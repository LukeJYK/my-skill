# Documents, Office & Media

> [!abstract] Scope
> Office document toolkits (docx/pptx/pdf/xlsx), file-to-markdown conversion, and image/report generation.

[Back to Skill Index](../index.md)

**Related maps:** [Scientific Writing, Figures & Publishing](research-writing.md) | [Literature Search & Knowledge Discovery](literature-discovery.md)

## Skills (6)

- [docx](../docx.md) — Use this skill whenever the user wants to create, read, edit, or manipulate Word documents (.docx files) or Word templates (.dotx files)
- [generate-image](../generate-image.md) — Generates or edits images with AI models through the OpenRouter Image API (Gemini, Seedream, Recraft, GPT-Image, Riverflow)
- [markitdown](../markitdown.md) — Converts heterogeneous documents and selected URIs to Markdown with Microsoft MarkItDown for text analysis, search, and LLM/RAG ingestion
- [pdf](../pdf.md) — Use this skill whenever the user wants to do anything with PDF files
- [pptx](../pptx.md) — Use this skill any time a .pptx or .potx file is involved in any way — as input, output, or both
- [xlsx](../xlsx.md) — Use this skill any time a spreadsheet file is the primary input or output
